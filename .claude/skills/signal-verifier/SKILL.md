# Signal Verifier — второе мнение по сигналу

База методологии — скил `nics-trading-analyst` (Ichimoku, Fibonacci/OTE, MA5/10/20, RSI, объём, price action, Yesterday Box). Этот скил добавляет процесс **перепроверки чужого сигнала**.

## Контекст стиля торговли
- Дейтрейдинг: позиция должна отработать в среднем **за ~1 час**. Тейки ставим в пределах реального часового хода (≈ 0.5–1.5 × ATR(14) на 15m/1h), не «мечтательные».
- Сканер не молчит: слабый сигнал не выкидываем, а честно маркируем (сильный / средний / слабый, против тренда 4h и т.п.).
- Только реальные данные. Нет живой цены/графика — говорим «не подтверждено», числа не придумываем.

## Вход
Сигнал: инструмент, направление, вход, TP1–TPn, SL, время выдачи (если есть).

## Процесс

1. **Живая цена и свежесть.** Получить текущую цену (WebFetch/WebSearch по надёжным источникам). Сравнить с входом: если цена уже прошла вход/TP1 или ушла за SL — сигнал **устарел**, так и сказать. Проверить, что вход достижим (лимит/рынок).
2. **Мульти-таймфрейм.** D1/4H — тренд и ключевые уровни; 1H — структура; 15m/5m — триггер. Yesterday Box (high/low/close вчера).
3. **Техника (каждый инструмент — «голос»):**
   - Структура и S/R, round numbers.
   - **Ложный пробой (liquidity sweep / fakeout):** был ли вынос хая/лоя с быстрым возвратом, закрытие тела за уровнем, объём на пробое; не заходит ли сигнал в ловушку.
   - **Fibonacci:** свинг, зона OTE 61.8–79%, расширения 127.2/161.8 для тейков.
   - **Ichimoku:** цена vs облако, Tenkan/Kijun, Chikou; толщина облака как препятствие по пути к тейкам.
   - MA5/10/20, RSI (дивергенции, перекупленность), объём, свечные паттерны.
   - Нужно ≥3 из 5 согласных голосов для «подтверждаю».
4. **Новости (обязательно).** Календарь на сегодня/ближайшие часы (CPI, NFP, FOMC, ставки, запасы нефти EIA/API, OPEC, отчётность по акциям, события по крипте/ETF) + свежие заголовки по инструменту и геополитике. Релиз в ближайшие 60 минут = отдельный риск: предупредить, предложить пропустить или напоминание «закрыть самому» (позиции автоматически не закрываем).
5. **Проверка параметров сигнала:**
   - SL за инвалидирующей структурой (свинг/край облака/ATR-буфер), не произвольный.
   - Каждый TP привязан к реальному уровню и достижим за ~1ч; нет сильных барьеров между входом и TP.
   - R:R ≥ 1:1.5 (иначе пометить).
   - Спред/ликвидность/сессия (азиатская тишина, открытие Лондона/NY).
6. **Вердикт** — один из:
   - ✅ **Подтверждаю** — параметры верны.
   - 🟡 **Подтверждаю с правками** — направление ок, поправить вход/SL/TP.
   - ❌ **Опровергаю** — причина (ложный пробой, против 4H без причины, новости, устарел, плохой R:R).
   - Если опровергаю — дать **свой вариант**: направление, вход, SL, TP1–TP3, ожидаемое время, сценарий-альтернатива и условие инвалидации.

## Формат ответа (кратко, решительно, по-русски)
```
📊 <ИНСТРУМЕНТ> — сигнал: <dir> @ <entry> | SL <x> | TP <a/b/c>
Цена сейчас: <p> (источник, время) → <актуален/устарел>
Контекст: D1/4H … | 1H … | 15m …
Техника: ложный пробой … | Fibo … | Ichimoku … | MA/RSI/объём …
Новости: … (риск на ближайшие часы: …)
Вердикт: ✅/🟡/❌ + 1–2 строки почему
Мой вариант: <dir> вход … SL … TP1/2/3 … R:R … ~время
Альтернатива/инвалидация: …
Уверенность: сильный/средний/слабый
```

## Правила
- Не размазывать: конкретные числа и уровни, без «зависит».
- Не выдавать за факт то, что не проверено (нет данных — написать, чего именно не хватило, и попросить скрин/цену).
- Это технический анализ, не финансовая рекомендация; отдельных дисклеймеров в каждом сообщении не нужно.
- Любое предложение изменить логику входа/стопа/тейков самой системы — с пометкой «перепроверить через 5 дней».
