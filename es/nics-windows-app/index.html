    Requisitos del sistema

    • Windows 10 o Windows 11, 64 bits
    • Microsoft Edge WebView2 (ya incluido en Windows 11 y en la mayoría de PCs con Windows 10; el instalador lo añade si falta)
    • Conexión a internet
    • Una cuenta NICS: acceso con Telegram o con código por e-mail

    Cómo instalar

    1. 1Pulsa «Descargar para Windows» y abre NICS-Trading-Ecosystem-Setup.exe.
    2. 2El instalador aún no tiene firma digital, así que Windows puede mostrar «Windows protegió su PC». Pulsa «Más información» y luego «Ejecutar de todas formas».
    3. 3Termina la instalación y abre NICS Trading Ecosystem desde el menú Inicio o el acceso directo del escritorio.
    4. 4Accede con Telegram o con un código por e-mail. Con una suscripción activa tu clave Pro se rellena sola.

    Preguntas

    ¿La app es gratis?

    Descargarla y acceder es gratis. Las pantallas de trading necesitan Pro, que viene con cualquier suscripción de pago activa de NICS Trading Ecosystem.

    ¿La app abre operaciones por mí?

    No. Ofrece análisis técnico; tú decides si abrir una posición con tu bróker.

    ¿Por qué Windows muestra un aviso?

    El instalador aún no tiene firma digital. Se está preparando la versión de Microsoft Store, firmada por Microsoft.

    ¿Tengo que actualizar la app?

    El espacio de trabajo dentro de la app carga la versión actual en cada inicio, así que las novedades llegan sin reinstalar.

    ¿Hay versión para Mac o móvil?

    Todavía no como app aparte. En Mac, móvil o tablet usa el panel web o la Mini App de Telegram con la misma cuenta.

    ¿Puedo usar una suscripción en varios dispositivos?

    Sí: el panel web y Telegram en todas partes, y la app de Windows en hasta dos ordenadores por clave.
